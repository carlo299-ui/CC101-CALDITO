# AWS Research

## Amazon Web Services

### 1. Brief Overview

Amazon Web Services (AWS) is a major cloud computing platform operated by Amazon. It provides a large collection of cloud services that organizations can use for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

AWS allows organizations to provision resources through the AWS Management Console, command-line tools, and APIs. Its services can be used by startups, educational institutions, government organizations, and large enterprises.

AWS provides a broad range of cloud-based products, including compute, storage, database, networking, machine learning, security, and developer services.

---

## 2. Global Infrastructure

AWS operates a global infrastructure consisting of geographic Regions and Availability Zones. AWS states that its infrastructure spans **39 geographic Regions and 124 Availability Zones**, with additional infrastructure planned.

An AWS Region is a separate geographic area, while Availability Zones are physically separated locations within a Region. This structure allows organizations to design applications for availability and resilience.

AWS also provides additional infrastructure options such as Local Zones and Outposts for workloads that need lower latency or hybrid environments.

---

## 3. Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services.

It provides centralized access to individual AWS service consoles. Users can search for services, manage resources, view notifications, access CloudShell, and monitor account and billing information.

The console can also be customized with widgets and favorite services.

---

## 4. Four Core Services

### 4.1 Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads in the cloud.

Common uses include:

* Web servers
* Application servers
* Development environments
* Enterprise applications

---

### 4.2 Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data.

It can be used for:

* Backups
* Images and videos
* Application files
* Data archives
* Static website content

---

### 4.3 Amazon RDS

Amazon Relational Database Service (RDS) is a managed relational database service.

It can help organizations run relational databases without having to manage all of the underlying database infrastructure themselves.

---

### 4.4 AWS IAM

AWS Identity and Access Management (IAM) controls authentication and authorization for AWS resources.

IAM allows organizations to manage users, roles, permissions, and policies. AWS documentation explains that IAM determines whether authenticated principals are allowed or denied access to AWS resources.

---

## 5. Three Advantages

### 1. Broad Service Selection

AWS provides a very large selection of cloud services covering many areas of IT. This gives organizations flexibility when designing cloud architectures.

### 2. Global Infrastructure

AWS has a large worldwide infrastructure consisting of Regions and Availability Zones, allowing organizations to deploy applications in different geographic locations.

### 3. Scalability

AWS services can be scaled according to workload requirements. Organizations can increase or decrease resources depending on demand.

---

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Web and mobile application hosting
* Data storage and backup
* Enterprise databases
* Disaster recovery
* E-commerce applications
* Artificial intelligence and machine learning
* Big data analytics
* Containerized applications
* Global application deployment
