#Reflection

This laboratory activity helped me understand the importance of cloud object storage and how it can be used in real-world applications.

First, object storage is better suited for storing millions of photos because it is designed to manage large amounts of unstructured data. Each photo is stored as an object with its own data, metadata, and unique identifier. Compared with traditional block storage, object storage is a practical option for applications that need to store and retrieve many images.

Second, Docker made deploying the MinIO storage server easier because it allowed me to run the service inside a container using a command with the required port mappings and environment variables. This reduced the need to configure the entire server manually and made the deployment process more organized.

Third, a bucket is a container used to organize and store objects in an object storage system. In this activity, the bucket named `client-photos` is intended to hold sample images and other uploaded files for the client's application.

Fourth, large enterprise companies can protect their object storage data through redundancy, replication, regular backups, and recovery procedures. These methods help reduce the risk of permanent data loss if a physical server fails. Monitoring and testing recovery processes are also important for maintaining data availability.

Finally, this activity gives me an opportunity to improve my confidence in navigating the Linux command line. Working with Docker commands, checking containers, and configuring services helps me become more familiar with technical tasks. With more practice, I hope to become more independent in deploying and managing cloud services.

Overall, this laboratory activity helped me connect cloud storage concepts with practical deployment skills. It also showed me why reliable storage, proper configuration, and data protection are important in cloud computing.
