# Research: Types of Cloud Storage

## Comparison of Cloud Storage Types

| Storage Type | Description | Primary Use Case | Cloud Provider Example |
|---|---|---|---|
| Block Storage | Stores data in fixed-sized blocks that can be managed independently. | Virtual machine disks and databases. | AWS EBS |
| File Storage | Stores data in files organized into folders and directories. | Shared files and team documents. | AWS EFS |
| Object Storage | Stores data as objects with data, metadata, and unique identifiers. | Images, videos, backups, and other unstructured data. | AWS S3 |

## Why Object Storage Is Best for Client Photos

Object Storage is a good choice for storing millions of user-uploaded photos because it can scale to handle large amounts of unstructured data. Each photo is stored as an object that can include metadata, making files easier to identify and manage. It is also well suited for applications that need to store and retrieve images over the internet.
