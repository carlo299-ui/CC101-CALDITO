# Laboratory 06 - Cloud Deployment Engineer

## Mission Overview
This laboratory focuses on deploying a private cloud storage system using Nextcloud, MariaDB, Docker, and Docker Compose.

## Objectives
- Understand two-tier application architecture.
- Create a Docker Compose YAML configuration.
- Deploy Nextcloud and MariaDB containers.
- Access the Nextcloud web interface.
- Learn Infrastructure as Code (IaC) principles.

## Commands Executed
Commands will be documented after completing the deployment activities.

## Skills Learned
- Docker Compose
- YAML configuration
- Multi-container deployment
- Linux command-line operations
- Cloud infrastructure documentation
